# 人设框架说明

这套结构对标 Character Card V2，按「模型对什么敏感」排序。改人设只需要动 `persona/character.yaml`，不用碰代码。

## 分层与落点

| 层 | 内容 | 在 yaml 里的字段 | 拼进 prompt 的位置 |
|---|---|---|---|
| Layer 1 | 身份对照表 | `identity_table` | 最前，紧跟开场 |
| Layer 1 | 身份锚点 / 性格 / 执念 / 说话风格 / 人物关系 | `identity` `personality` `core_obsessions` `speech_style` `relationships` | 前段 |
| Layer 2 | 情境-反应矩阵 | `reactions` | 中段 |
| 背景 | 世界观 | `world` | 中段 |
| Layer 3 | 当前场景（静态部分） | `scenes` `current_scene` `auto_scene` | 后段 |
| Layer 4 | 长期记忆 | `memory` + `persona/memory.md` | 后段 |
| 示例 | few-shot 对话 | `examples` | 倒数第二 |
| Layer 0 | 硬约束 | `hard_rules` | **最后** |

Layer 3 的动态部分（时间、空闲间隔）不在 system prompt 里，而是每轮拼成一条 `system` 消息，贴在对话历史末尾、紧邻生成位置。只用于这一次请求，不写进历史。

## 各层为什么放这个位置

- **身份对照表放最前**：灵魂互换这种绕的设定，散文条目压不住，表格能。模型对开头的角色定义最敏感。
- **情境-反应放中段**：它是「行为说明书」，比形容词有效，但不如身份重要。
- **硬约束放最后**：模型对结尾的遵循度最高。长度、格式、禁止项都放这里。
- **示例放硬约束前面**：示例定语感，硬约束定边界，两者都在尾部，互相加强。

## 代码改动

### `codes/config.py`

| 参数 | 值 | 作用 |
|---|---|---|
| `MAX_TOKENS` | 200 | 约 100~140 汉字，和打字机速度对齐 |
| `GREETING_MAX_TOKENS` | 100 | 开机问候更短 |
| `FREQUENCY_PENALTY` | 0.4 | 压制口头禅循环 |
| `SCENE_AUTO_ENABLED` | True | 按时间自动切场景 |
| `MAX_HISTORY` | 14 | 从 20 降下来，窗口太长会模仿自己的腔调 |

### `codes/persona.py`

- `Persona` 新增字段：`identity_table` `reactions` `hard_rules` `examples` `auto_scene`
- `build_system_prompt()` 改成按上表顺序拼接
- 新增 `build_state_block()`：拼「此刻」状态块
- `PersonaStore` 新增 `clear_scene_override()` `is_auto_scene` `_auto_scene()`
- `active_scene` 优先级：手动覆盖 → 按小时自动 → `current_scene`
- 兼容旧文件：没有 `reactions` 时回退读 `rules`

### `codes/api_client.py`

- `chat()` 在用户消息后追加一条临时 `system` 状态消息，请求完就丢弃
- 记录 `_last_user_at` / `_turn_count`，用来生成「隔了多久」「第一次开口」这类提示
- 新增 `set_auto_scene()`
- 三个调用点统一用 `MAX_TOKENS` / `FREQUENCY_PENALTY`

### `codes/pet_window.py`

- 右键「切换场景」菜单顶部加「自动（按时间）」，手动选过场景后以手动为准

## 状态块长什么样

```
【此刻】只用于这一轮，不要复述这段话。
现在是2026年11月17日 星期二 22:51 夜里。
你正处在「夜深了」这个场景里。
他隔了一会儿才开口。
他这句话很短，别多问。
```

## 怎么调

- **改语气**：动 `examples`，比改 `personality` 有效十倍。
- **改长度**：动 `hard_rules` 第一条，同时看 `MAX_TOKENS`。
- **改场景**：在 `scenes` 加一条，在 `auto_scene` 里配时段。
- **加记忆**：写 `persona/memory.md`，以 `#` 开头的行不会发给模型。

## 已知限制

- 场景自动切换只看小时，不看用户实际在做什么。
- 状态块里的「关系温度」目前只有空闲时长和消息长度两个信号，没有真正的情感推断。
- `MAX_HISTORY` 仍是滑动窗口，没有做摘要压缩，聊久了早期内容会丢。
